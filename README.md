### About Me

I'm a software engineer from India learning and building in public across **Web3, AI agents, and cryptographic systems**. I believe the best way to learn is to ship real things, document the struggle, and share everything openly.

Currently focused on:

- 🔐 **Blockchain infrastructure** for autonomous AI agents (TEE enclaves, hardware key vaults, MCP servers)
- 🧠 **Privacy-preserving AI** using Fully Homomorphic Encryption (FHE)
- ⛓️ **Smart contract security** and onchain tooling
- 📢 **Building in public** on Twitter and GitHub every single day
